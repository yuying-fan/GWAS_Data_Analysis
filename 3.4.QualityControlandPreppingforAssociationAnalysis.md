# 4. Quality Control and Prepping for Association Analysis

### Variant Filtering

For our first QC step, we will be filtering our SNPs using [vcftools](http://vcftools.sourceforge.net/). 
```
/usr/local/bin/vcftools --vcf fullmerged.vcf --out filter_1.vcf --remove-indels --max-alleles 2 --maf 0.05 --minQ 20 --max-missing 0.95 --recode --recode-INFO-all
```
