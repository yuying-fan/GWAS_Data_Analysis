# 4. Quality Control and Prepping for Association Analysis

### Variant Filtering

For our first QC step, we will be filtering our SNPs using [vcftools](http://vcftools.sourceforge.net/). 
```
/usr/local/bin/vcftools --vcf fullmerged.vcf --out filter_1 --remove-indels --max-alleles 2 --maf 0.05 --minQ 20 --max-missing 0.95 --recode --recode-INFO-all
```

After filtering, kept 69829 out of a possible 330716 Sites

### Linkage-Disequilibrium (LD) Pruning 

We will 

First, we will convert the vcf into plink format as we will be doing pruning in Plink. First, the vcf contains the chromosome name notation used in the reference genome Af293 (e.g. NC_007194.1, which is chromosome 1) but there will be issues converting to plink if the "CHROM" column of your vcf file isn't numerical. Therefore, we will convert these NC_x names into their numerical value using ```sed```

```
sed -i 's/NC_007194.1/1/g;s/NC_007195.1/2/g;s/NC_007196.1/3/g;s/NC_007197.1/4/g;s/NC_007198.1/5/g;s/NC_007199.1/6/g;s/NC_007200.1/7/g;s/NC_007201.1/8/g' filter_1.recode.vcf
```

```
/usr/local/bin/vcftools --vcf filter_1.recode.vcf --plink --out filter_1plink
```

We will now download plink 1.90 beta. 
```
wget http://s3.amazonaws.com/plink1-assets/plink_linux_x86_64_20201019.zip
```

```
unzip plink_linux_x86_64_20201019.zip 
```

```
plink --noweb --allow-no-sex --allow-extra-chr --make-founders --file filter_1plink --indep 50 10 2 --out LDpruned
```

```
plink --allow-extra-chr --file filter_1plink --extract LDpruned.prune.in --make-bed --out pruneddata
```

```
plink --allow-extra-chr --bfile pruneddata --recode vcf --out pruned_2
```
