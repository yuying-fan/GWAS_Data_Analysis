# 4. Quality Control and Prepping for Association Analysis

### Variant Filtering

For our first QC step, we will be filtering our SNPs using [vcftools](http://vcftools.sourceforge.net/). 
```
/usr/local/bin/vcftools --vcf allmergedn.vcf --out Q15M90.vcf --remove-indels --max-alleles 2 --max-missing 0.9 --minQ 15 --maf 0.05 --recode --recode-INFO-all
```
