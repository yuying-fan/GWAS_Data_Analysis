The next step is to use the nano text editor to create a shell script named download.sh

```nano download.sh```

Then put inside the editor the script below. This script will use the ```SRA_SRR.txt``` (which contains the accession and run numbers of the strains) to download the sequences for these strains. The strain sequences will be saved to their own directory, which will be named after their run number (e.g. SRR12894198).
```
i=0
line2="hello"
while read line; do
        i=$(( i+1 ))
        if (($i % 2)) ; then
                echo $i
                mkdir $line
                line2=$line
                echo $line2
        else
            	for srr in $line
                do
                  	echo $srr
                        /usr/local/sratoolkit/prefetch $srr
                        mv /home/yuying/ncbi/public/sra/* $line2
                done
        fi
done < SRA_SRR.txt
```

After inputting the text above into ```download.sh``` and saving the changes, the script can then be ran with this command:
```bash download.sh```

_AS A NOTE: I have encountered problems downloading a large amount of files all at once from NCBI using prefetch. If some of your strain directories are empty, you may have to edit the SRA_SRR.txt to contain just those undownloaded strains, remove the empty directories, and redownload again. You can check which strains have empty folders using ```find . -type d -empty -print```_

run=()

        run=$(find $line -type f)
        for id in $run
        do

Then run it:

### Downloading the reference genome Af293
The reference genome Af293 can then be downloaded from NCBI. The line below will download the FASTA format of the Af293 genome (with the extension .fna.gz). 

```
wget https://ftp.ncbi.nlm.nih.gov/genomes/all/GCF/000/002/655/GCF_000002655.1_ASM265v1/GCF_000002655.1_ASM265v1_genomic.fna.gz
```

Then expand this file using the gunzip command:
```
gunzip GCF_000002655.1_ASM265v1_genomic.fna.gz
```

For simplicity, the name of this file will be changed to Af293.fa
```
mv GCF_000002655.1_ASM265v1_genomic.fna Af293.fa
```

An index file for the reference genome is then made as we will be using bwa for alignment latter on
```
bwa index Af293.fa 
```
