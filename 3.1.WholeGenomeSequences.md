The next step is to create a shell script called ```download.sh```

```nano download.sh```

Put inside this script the text below.
```
i=0
line2="hello"
while read line; do
        i=$(( i+1 ))
        if (($i % 2)) ; then
                echo $i
                mkdir $line
                line2=$line
                echo $line2
        else
            	for srr in $line
                do
                  	echo $srr
                        /usr/local/sratoolkit/prefetch $srr
                        mv /home/yuying/ncbi/public/sra/* $line2
                done
        fi
done < SRA_SRR.txt
```
This script will use the ```SRA_SRR.txt``` (which contains the accession and run numbers of the strains) to download the strain's raw sequences from NCBI. The strain sequences will be saved to their own directory, which will be named after their run number (for example, "SRR12894198").

After inputting the text above into ```download.sh``` and saving the changes, the script can then be ran with this command:
```
bash download.sh
```

_AS A NOTE: I have encountered problems downloading a large amount of files all at once from NCBI using the prefetch tool. If some of your strain directories are empty, you may have to edit the SRA_SRR.txt to contain just those undownloaded strains and redownload again. You can check which strains have empty folders (i.e. did not download) using ```find . -type d -empty -print```_

After saving this file, we will create a script called ```fastqextract.sh```
```
nano fastqextract.sh
```

Input inside of this script the text below:
```
run=()
while read line; do
        run=$(find $line -type f)
        for id in $run
        do
          	/usr/local/sratoolkit/fastq-dump --skip-technical --outdir $line --split-files $id
        done
done < SRA.txt
```
This script will find the downloaded strain sequences file, which are named after their accession number, in our ```SEQAF``` directory and use [SRA Toolkit](https://hpc.nih.gov/apps/sratoolkit.html)'s fastqdump to convert the sra files into fastq format.  
- ```--skip-technical``` is used as we only want the biological reads, we don't want any potential technical reads so thus we remove it using this
- ```--split-files``` is used as these are all paired-end reads. This will seperate the read into two fastq files for each strain; put the forward and reverse reads in two seperate files.
- A great explanation of fastqdump flags can also be found [here](https://edwards.sdsu.edu/research/fastq-dump/) 

After saving the script, we will then run it:
```
bash fastqextract.sh
```

After this is complete, you should see that the strain directories now also have two fastq files (forward and reverse fastq files)

### Downloading and preparing the reference genome Af293
The reference genome Af293 can be downloaded from NCBI. The line below will download the FASTA format of the Af293 genome (which will have the extension ```.fna.gz```). 

```
wget https://ftp.ncbi.nlm.nih.gov/genomes/all/GCF/000/002/655/GCF_000002655.1_ASM265v1/GCF_000002655.1_ASM265v1_genomic.fna.gz
```

We will expand this file using the gunzip command:
```
gunzip GCF_000002655.1_ASM265v1_genomic.fna.gz
```

For simplicity, the name of this reference fasta file will be changed to Af293.fa
```
mv GCF_000002655.1_ASM265v1_genomic.fna Af293.fa
```

An index file for the reference genome is then made using [bwa](http://bio-bwa.sourceforge.net/bwa.shtml). This will be done in advance as we will be using BWA-MEM for read alignment later on
```
bwa index Af293.fa 
```
