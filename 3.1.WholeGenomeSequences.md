```nano download.sh```

```
i=0
line2="hello"
while read line; do
        i=$(( i+1 ))
        if (($i % 2)) ; then
                echo $i
                mkdir $line
                line2=$line
                echo $line2
        else
            	for srr in $line
                do
                  	echo $srr
                        /usr/local/sratoolkit/prefetch $srr
                        mv /home/yuying/ncbi/public/sra/* $line2
                done
        fi
done < SRA_SRR.txt
```
```nohup bash download.sh &```

Sometimes there can be problems downloading if you are getting a lot of files so you may have to redownload some strains. Check which files are empty and redownload them
