# 1. Whole Genome Sequences

## Directory Set up

First, make a directory that you will be working in. Here, I have named this folder "SEQAF"
```
mkdir SEQAF; cd SEQAF
```

## Downloading the Sequences from NCBI

In this new directory, you will be downloading the raw sequences for the 32 strains from NCBI using the [SRAtoolkit](https://hpc.nih.gov/apps/sratoolkit.html) prefetch tool

This will be done by making a text file containing the accession and run numbers of these 32 strains. The text should cycle through each strain with the accession number in the first line and the run number in the subsequent second line.

```nano SRA_SRR.txt```

```
DRS075098
DRR146814
ERS2867139
ERR2863830
```

```nano download.sh```

```
i=0
line2="hello"
while read line; do
        i=$(( i+1 ))
        if (($i % 2)) ; then
                echo $i
                mkdir $line
                line2=$line
                echo $line2
        else
            	for srr in $line
                do
                  	echo $srr
                        /usr/local/sratoolkit/prefetch $srr
                        mv /home/yuying/ncbi/public/sra/* $line2
                done
        fi
done < SRA_SRR.txt
```
```nohup bash download.sh &```

Sometimes there can be problems downloading if you are getting a lot of files so you may have to redownload some strains. Check which files are empty and redownload them
```find . -type d -empty -print```
