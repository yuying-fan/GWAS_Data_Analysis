# 6. Visualization of GWAS Results

You now have the two files containing p-values obtained from Plink and Tassel, ```Plink_for_plot.txt``` and ```Tassel_for_plot.txt```, on your local machine

Using the information from these files, we can now construct our Manhattan and QQ plot using the package [qqman](https://cran.r-project.org/web/packages/qqman/vignettes/qqman.html) on RStudio. 

Open up RStudio and create a new R Script. Set your working directory to what works for you; I used my Desktop. 

### Plink Result Visualization

We will start off with the Plink results. You can input and run the text below in your RStudio:
```
# First, I check the Plink file is present on my Desktop
file.exists("/Users/yuyingfan/Desktop/Plink_for_plot.txt")

# We then read the table into RStudio and create a dataframe called "PlinkVis"
PlinkVis <- read.table("/Users/yuyingfan/Desktop/Plink_for_plot.txt")

# With head(), you can see that the columns headers are V1, V2 and V3 while the first row contains the actual headers (CHR, BP and P). Thus we will rename the column headers and remove that first row:
head(PlinkVis)
library(plyr)
PlinkVis <- rename(PlinkVis, c("V1"="CHR", "V2"="BP", "V3"="P"))
PlinkVis = PlinkVis[-1,]

# The package qqman requires our data to be organized in four columns named SNP, CHR, BP and P. We are missing the SNP column, which is just a SNP ID. Here we will just insert another column of sequential numbers for our SNP ID:
PlinkVis$SNP <- seq.int(nrow(PlinkVis))

# If you look at the structure of our "PlinkVis" data frame, our three columns CHR, BP and P are factors, not numeric. Thus we will change these three columns into numeric:
str(PlinkVis)
PlinkVis$CHR <- as.numeric(as.character(PlinkVis$CHR))
PlinkVis$BP <- as.numeric(as.character(PlinkVis$BP))
PlinkVis$P <- as.numeric(as.character(PlinkVis$P))

# We will use the package qqman to create our Manhattan and QQ plot:
library(qqman)
manhattan(PlinkVis, main = "Plink - Amphotericin B", ylim = c(0, 7), cex = 0.7, 
          cex.axis = 0.9, col = c("blue4", "orange3"), suggestiveline = F, genomewideline = F)
qq(PlinkVis$P)
```

#### Optional Next Step - I then save these two images to my desktop in png format using these parameters:
