# 3. Alignment and Variant Calling

### Aligning reads to reference genome

We will now be aligning our reads to a reference genome. To do this for all 32 of our strains, we will automate this process using a bash script.

Create a script called ```alignment.sh```

```
nano alignment.sh
```

Inside of this script, input in the text below:
```
run=()

run=$(find /2/scratch/yuying/SEQAF -type d)

for id in $run

do

        idd=$(basename "$id")

        cd /2/scratch/yuying/SEQAF/${idd}

        f=$(find /2/scratch/yuying/SEQAF/${idd} -type f |grep _1.fastq|grep -v fastqc)

        R1=$(basename "$f")

        R2=${R1/_1.fastq/_2.fastq}

        p=${R1/_1.fastq/}

        echo $p

        bwa mem -t 16 /2/scratch/yuying/SEQAF/Af293.fa -R "@RG\tID:${p}\tLB:*\tPL:ILLUMINA\tPM:HISEQ\tSM:${p}" $R1 $R2 |samtools view -@4 -bS | samtools sort -o ${p}.sorted.bam

        java -jar /usr/local/picard-tools/picard.jar MarkDuplicates I=${p}.sorted.bam O=${p}.sorted.markdup.bam M=${p}.markdup_metrics.txt

        samtools index ${p}.sorted.markdup.bam

        cd ..

done
```

We can then run this on our data with:
```
bash alignment.sh
```

### Variant calling

As a note, we will be variant calling using [FreeBayes](https://github.com/freebayes/freebayes). From [forums](https://www.biostars.org/p/342533/) and [GATK documentation](https://github.com/broadinstitute/gatk-docs/blob/master/blog-2012-to-2019/2016-06-01-Version_highlights_for_GATK_version_3.6.md?id=7712), indel realignment is not needed if you plan to use a variant caller that performs a haplotype assembly step. Since FreeBayes performs a haplotype assembly step, we will be going directly into variant calling.

First, while still being in the ```SEQAF``` directory, we will make a new folder for all the bam files called ```bamfiles```
```
mkdir bamfiles
```

Then we will move all the ```.sorted.markdup.bam``` files and their corresponding index files (```.sorted.markdup.bam.bai```) to this folder:
```
mv ./*/*.sorted.markdup.bam* bamfiles/
```

After moving everything over, move to the ```bamfiles``` folder (```cd bamfiles```). Variant calling can now be done using FreeBayes. I will be doing this on a chromosome-by-chromosome basis, as doing all eight chromosomes at once will take a long time and use up a lot of CPU (It also allows calling SNPs in parallel). With the vcf file being split by chromosome, we will now combine all these files to obtain one complete vcf file of all eight chromosomes. To do so, we will be doing two steps. The first is just to grab the header off one of the vcf file (e.g. ```allmerged1.vcf```) and then concatenate all the remaining vcf files without the header. These two steps are show below:

**I) Grab the header from one vcf. In this example, we will use ```allmerged1.vcf```:**
```
grep '^#' allmerged1.vcf > fullmerged.vcf
```
**II) Concatenate all the vcf files, without headers:**
```
grep -h -v '^#' allmerged1.vcf allmerged2.vcf allmerged3.vcf allmerged4.vcf allmerged5.vcf allmerged6.vcf allmerged7.vcf allmerged8.vcf  >> fullmerged.vcf
```
- -h (or --no-filename) will prevent the addition of filenames into your output when combining more than one file.
