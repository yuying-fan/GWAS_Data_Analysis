After saving the phenotype file, we will start to work on the genotype file. In TASSEL, we will be conducting out association analysis via a mixed linear model (MLM). In this analysis, a genetic marker based kinship matrix will be used in combination with population structure obtained by principal component analysis (PCA). Therefore, to MLM association analysis in TASSEL, we need 4 files: the genotype file, the phenotype file, a kinship matrix, and a population structure file.

First, we will obtain the population structure file. We will start off by doing a PCA with our genotype file ```pruned_2tassel.vcf``` using 20 PCs to deteremine how many components we will include in our association analysis (to explain for population structure)

```
./tassel-5-standalone/run_pipeline.pl -importGuess pruned_2tassel.vcf -PrincipalComponentsPlugin -covariance true -ncomponents 20 -endPlugin -export PCAtassel
```
- ```-importGuess``` is used for the input file, pruned_2tassel.vcf
- ```-PrincipalComponentsPlugin``` is used to perform the PCA
- ```-ncomponents``` is set to 20 principal components. This is an arbitrary number as we will be using the PCA results to determine number of components to use. 

After PCA has finished running, three resulting files will be obtained named PCAtassel1.txt, PCAtassel2.txt, and PCAtassel3.txt. These files contain the principal components requested by user, the eigenvalues, and the eigenvectors, respectively.

A plot of the eigenvalues versus PCs will be used to help decide which PC's are most important to be used for the association analysis. This can be done by just copying the eigenvalues from ```PCAtassel2.txt``` into Excel and making a scatter plot with PC components on x-axis and eigenvalues on y-axis (this plot is called a scree plot). 

From this excel line plot, you will see a "elbow" in the graph ([example](https://en.wikipedia.org/wiki/Scree_plot)). The bend of this elbow will be the cutting-off point in terms of number of PCs to use for the association analysis. 

From our TASSEL obtained results, this elbow in our plot happens at around 9 PCs before leveling off. Therefore, we will be using 9 PCs.

We will run the PCA command again but this time with just 9 PCs. These files will be save as ```PCA9tassel```, which will later be used as the population structure file in our MLM analysis:
```
./tassel-5-standalone/run_pipeline.pl -importGuess pruned_2.vcf -PrincipalComponentsPlugin -covariance true -ncomponents 9 -endPlugin -export PCA9tassel
```
