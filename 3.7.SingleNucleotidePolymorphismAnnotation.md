# 6. Single Nucleotide Polymorphism Annotation

We now have the p-values for all our SNPs after conducting the association analysis. For my project, rather than determining a p-value threshold (e.g. Bonferroni corrected significance threshold) or applying additional false discovery rate methods, I will first be investigating the 10 SNPs with the lowest p-values. This method was obtained and modified from [Genome-Wide Association for Itraconazole Sensitivity in Non-resistant Clinical Isolates of Aspergillus fumigatus](https://www.frontiersin.org/articles/10.3389/ffunb.2020.617338/full), a recent paper on A. fumigatus investigating sensitivity to the antifungal itraconazole using a GWAS. They looked at the top 20 SNPs as they had more SNP sites (a total of ~60,000), therefore this value has been modified to 10 SNPs for our case.

However, we will need to also annotate our SNPs to determine where they are located and the type (e.g. synonymous, missense, etc.). To do so, we will be using the gene annotation of our reference genome, Af293.

### Annotating our vcf file

We will go back into the cluster, in our scratch's ```bamfiles``` directory (```/2/scratch/yuying/SEQAF/bamfiles/```). In this folder, we will download the annotation file for Af293 from NCBI. 
```
wget https://ftp.ncbi.nlm.nih.gov/genomes/all/GCF/000/002/655/GCF_000002655.1_ASM265v1/GCF_000002655.1_ASM265v1_genomic.gff.gz
```

Then expand the file:
```
gunzip GCF_000002655.1_ASM265v1_genomic.gff.gz 
```

For simplicity, we will change name of this gff file to Af293.gff
```
mv GCF_000002655.1_ASM265v1_genomic.gff Af293.gff
```

I will be using [SnpEff](https://pcingola.github.io/SnpEff/se_introduction/) for variant annotation. To download SnpEff, run the commands below:

```
wget https://snpeff.blob.core.windows.net/versions/snpEff_latest_core.zip
```
```
unzip snpEff_latest_core.zip
```

This will provide a new folder in your ```bamfiles``` directory called ```snpEff```, which we will first enter:
```
cd snpEff
```

SnpEff needs a database to perform variant annotation. There is a long list of pre-built databases for over 2,500 genomes SnpEff has. A. fumigatus Af293 already has a pre-built database called ```Aspergillus_fumigatus``` so we will just download this Af293 genome database from SnpEff by running the line below:
```
java -jar snpEff.jar download -v Aspergillus_fumigatus
```

We can now annotate our vcf file ```pihat_removed_3_tassel.vcf``` using SnpEff. First we need to enter back into our ```bamfiles``` folder (```cd ..```) and then we can run the command:
```
java -jar /2/scratch/yuying/SEQAF/bamfiles/snpEff/snpEff.jar Aspergillus_fumigatus pihat_removed_3_tassel.vcf > pihat_removed_3_tassel.snpEff.vcf
```

The generated ```pihat_removed_3_tassel.snpEff.vcf``` file will contain variant annotations that we will use to investigate the top 10 SNPs (lowest p-value) we obtained from Plink and Tassel.

### Variant Annotation on GWAS Results

In our ```bamfiles``` folder, we have the p-value results of our GWAS in two files: ```Plink_for_plot.txt``` and ```Tassel_for_plot.txt```. The third column of both files contain the p-values. We will use these files to determine our top 10 SNPs for both programs, Plink and Tassel. These two files do contain p-values of N/A, therefore, before sorting, we will remove these rows:
```
grep -iv 'NA' Plink_for_plot.txt > Plink_p-values.txt
```
```
grep -iv 'NA' Tassel_for_plot.txt > Tassel_p-values.txt
```

We will now pull our the top 10 SNPs using the new p-values text files we just created:
```
cat Plink_p-values.txt | sort -g -k 3 | head -11 > Top10Plink.txt
```
```
cat Tassel_p-values.txt | sort -g -k 3 | head -11 > Top10Tassel.txt
```
