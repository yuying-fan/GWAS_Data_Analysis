# 6. Single Nucleotide Polymorphism Annotation

We now have the p-values for all our SNPs after conducting the association analysis. For my project, rather than determining a p-value threshold (e.g. Bonferroni corrected significance threshold) or applying additional false discovery rate methods, I will first be investigating the 10 SNPs with the lowest p-values. This method was obtained and modified from [Genome-Wide Association for Itraconazole Sensitivity in Non-resistant Clinical Isolates of Aspergillus fumigatus](https://www.frontiersin.org/articles/10.3389/ffunb.2020.617338/full), a recent paper on A. fumigatus investigating sensitivity to the antifungal itraconazole using a GWAS. They looked at the top 20 SNPs as they had more SNP sites (a total of ~60,000), therefore this value has been modified to 10 SNPs for our case.

### Sorting the GWAS Results

First, we will go back into the cluster. In our ```bamfiles``` folder, we have the p-value results of our GWAS in two files: ```Plink_for_plot.txt``` and ```Tassel_for_plot.txt```. The third column of both files contain the p-values. We will use these files to determine our top 10 SNPs for both programs, Plink and Tassel. These two files do contain p-values of N/A, therefore, before sorting, we will remove these rows:
```
grep -iv 'NA' Plink_for_plot.txt > Plink_p-values.txt
```
```
grep -iv 'NA' Tassel_for_plot.txt > Tassel_p-values.txt
```

We will now pull our the top 10 SNPs using the new p-values text files we just created:
```
cat Plink_p-values.txt | sort -g -k 3 | head -11 > Top10Plink.txt
```
```
cat Tassel_p-values.txt | sort -g -k 3 | head -11 > Top10Tassel.txt
```

However, we will need to also annotate our SNPs to determine where they are located and the type (e.g. synonymous, missense, etc.). To do so, we will be using the gene annotation of our reference genome, Af293.

### Annotating our vcf file

We will now annotate our vcf file to obtain information on the SNPs. I will be using [SnpEff](https://pcingola.github.io/SnpEff/se_introduction/) for variant annotation. Our lab has already created a database for Af293 using the genome and annotation file found in NCBI. Instead of going through the process of download SnpEff and creating a new database for the genome, you can copy over this snpEff folder from my ```/2/scratch/yuying/snpEff``` to your ```bamfiles``` directory. 

In the ```bamfiles``` directory, you can run snpEff on our ```fullmerged.vcf``` file. _This is done on the fullmerged.vcf because the database was created using the chromosome notation of ```NC_00xxxx.x```. I will also be doing linkage disequilibrium later on (not in this course project) thus it would be best to run this on the un-pruned vcf file, ```fullmerged.vcf```. _
```
java -jar /2/scratch/yuying/snpEff/snpEff.jar Af293 fullmerged.vcf > vcfannotation.snpEff.vcf
```

The generated ```vcfannotation.snpEff.vcf``` file will contain variant annotations that we will use to investigate the top 10 SNPs (lowest p-value) we obtained from Plink and Tassel.

### Annotating the SNPs

We will then use the annotated vcf file ```pihat_removed_3_tassel.snpEff.vcf``` to determine the effect of each SNP. This is done for each SNP using the ```grep``` command below, which will look through the vcf file and find lines containing the position/base pair number. Only one example is provided below, however the same ```grep``` command is used for all SNP positions to find the variant annotation.
```
grep -w 718971 pihat_removed_3_tassel.snpEff.vcf
```
