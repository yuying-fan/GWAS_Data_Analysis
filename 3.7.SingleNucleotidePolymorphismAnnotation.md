# 6. Single Nucleotide Polymorphism Annotation

We now have the p-values for all our SNPs after conducting the association analysis. For my project, rather than determining a p-value threshold (e.g. Bonferroni corrected significance threshold) or applying additional false discovery rate methods, I will first be investigating the 10 SNPs with the lowest p-values. This method was obtained and modified from [Genome-Wide Association for Itraconazole Sensitivity in Non-resistant Clinical Isolates of Aspergillus fumigatus](https://www.frontiersin.org/articles/10.3389/ffunb.2020.617338/full), a recent paper on A. fumigatus investigating sensitivity to the antifungal itraconazole using a GWAS.

However, we will need to also annotate our SNPs to determine where they are located and the SNP type (e.g. synonymous, missense, etc.). To do so, we will be using the gene annotation of our reference genome, Af293.

Using the information from these files, we can now construct our Manhattan and QQ plot using the package [qqman](https://cran.r-project.org/web/packages/qqman/vignettes/qqman.html). Open up RStudio and create a new R Script. Set your working directory to what works for you, I used my Desktop.
