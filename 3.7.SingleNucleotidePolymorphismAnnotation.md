# 7. Single Nucleotide Polymorphism Annotation

We now have the p-values for all our SNPs after conducting the association analysis. For my project, I will be investigating the 10 SNPs with the lowest p-values of each method (Plink & Tassel). This method was obtained and modified from [Genome-Wide Association for Itraconazole Sensitivity in Non-resistant Clinical Isolates of Aspergillus fumigatus](https://www.frontiersin.org/articles/10.3389/ffunb.2020.617338/full), a recent paper on _A. fumigatus_ that investigated sensitivity to the antifungal itraconazole using a GWAS. They looked at the top 20 SNPs as they had more SNP sites (a total of ~60,000), therefore this value has been modified to 10 SNPs for our case.

### Sorting the GWAS Results

First, we will go back into the cluster. In our ```bamfiles``` folder, we have the p-value results of our GWAS in two files: ```Plink_for_plot.txt``` and ```Tassel_for_plot.txt```. The third column of both files contains the p-values. We will use these files to determine our top 10 SNPs for Plink and for Tassel. These two files do contain p-values that are NA, therefore before sorting, we will remove these rows of NA:
```
grep -iv 'NA' Plink_for_plot.txt > Plink_p-values.txt
```
```
grep -iv 'NA' Tassel_for_plot.txt > Tassel_p-values.txt
```

We will now pull out the top 10 SNPs using the p-values text files we just created (```Plink_p-values.txt``` and ```Tassel_p-values.txt```):
```
cat Plink_p-values.txt | sort -g -k 3 | head -11 > Top10Plink.txt
```
```
cat Tassel_p-values.txt | sort -g -k 3 | head -11 > Top10Tassel.txt
```

However, we will need to also annotate our SNPs to determine where they are located (gene-wise) and the SNP type (e.g. synonymous, missense, etc.). To do so, we will be using the gene annotation of our reference genome, Af293.

### Annotating our vcf file

We will now annotate our vcf file to obtain information on the SNPs. I will be using [SnpEff](https://pcingola.github.io/SnpEff/se_introduction/) for variant annotation. Another labmate has already created a database for Af293 using the genome file and annotation file obtained from NCBI. Instead of going through the process of downloading SnpEff as well as building a new database for Af293, you can just copy over our lab's snpEff folder from my ```/2/scratch/yuying/snpEff``` to your ```bamfiles``` directory. 

In the ```bamfiles``` directory, you can now run snpEff on the ```fullmerged.vcf``` file. This is being done on the fullmerged.vcf because the Af293 database was created using the chromosome notation of ```NC_00xxxx.x```, which we had changed into numeric for our donwstream vcf files. I will also later on be looking into highly-linked SNPs to the top 10 SNPs (not covered in this course project), thus it would be best to run this on the un-pruned vcf file ```fullmerged.vcf```. The command for this is found below (Note: we are in ```bamfiles``` folder):
```
java -jar /2/scratch/yuying/snpEff/snpEff.jar Af293 fullmerged.vcf > vcfannotation.snpEff.vcf
```

The generated ```vcfannotation.snpEff.vcf``` will contain variant annotation that we will use to investigate the top 10 SNPs we obtained from Plink and from Tassel.

### Annotating the top 10 SNPs
